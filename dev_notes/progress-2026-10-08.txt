FINDINGS
--------
- Test questions leaked into training data. ARC's official splits repeat a
  few questions (1 exact copy, 3 with different options). Sampling now drops
  train/val questions whose text matches a test question (4 ARC, 4 SWAG).
- Some CommonsenseQA questions list the same option twice, sometimes the
  correct one (ambiguous). Sampling now drops them (24 test-pool, 122
  train-pool; 1 in SWAG). The check is case-sensitive so ARC genotype options
  like "WW or Ww" vs "WW or ww" are kept.
- SWAG dedupe does NOT cause class imbalance: questions are dropped from the
  73,546-question pool before drawing, so every split is still full size and
  answer positions are balanced.
- decision-index (the Jev prompt format we reuse) has no template for
  CommonsenseQA or SWAG; ours copy ARC's and HellaSwag's. Noted in PLAN A9.
- Claude Sonnet 5.5 tends to write textbook questions that ARC already
  contains (e.g. "Which material is the best conductor of electricity?").
  Drafts with similarity >= 0.75 to a real benchmark question are now
  discarded and replaced automatically (24 replaced). 60 more (0.6-0.75) are
  flagged in the review sheet; most look like false alarms.
- Qwen and Gemma both return letter probabilities (logprobs) when reasoning
  is switched off. OpenRouter sent them to different providers, so
  09_run_llm.py should pin one provider per model.
- Part B: Cronbach's alpha over 5 repeat runs of one condition comes out near
  0 even for a perfectly consistent model. It has to be computed across
  conditions (baseline + personas) x runs. Noted in PLAN B1 as open.
- The pilot already caught a meaning error: one model rewrote a wrong option
  ("The water will melt") so it became a second correct answer.
