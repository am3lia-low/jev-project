JEV BENCHMARKS - HELPER FILES TO BUILD
======================================
Shared code for the jev benchmarks scripts. Goes in 01-jev-benchmarks/helpers/,
except cache.py, stats.py, openrouter.py and models.py, which are in
src/jev_common/ (shared with Part B).
Section references (A1, A2, ...) are to docs/PLAN.md, Part A.
Build order: 1-4 and 11 first (02_sample.py needs them), then 5-6, then the rest.
No tests are being written for the helpers.
Tick [x] when done.

CORE DATA (needed by every script)
[x] 1. schema.py      One question format shared by all scripts: id, dataset, split,
                      question, options, answer letter, original order, shuffled
                      order, version. Plus JSONL read/write.
[x] 2. ids.py         Stable IDs like "arcc-test-0417", shared by every version of
                      a question (A2 rule 5).
[x] 3. labels.py      Normalise answer labels to A-E (ARC uses 1/2/3/4); convert
                      between letters and positions (A2 rule 4).
[x] 4. shuffle.py     Seeded balanced shuffle: correct position balanced within each
                      option-count group of 3, 4, 5 (A2 rule 3). Also reused to
                      balance the original's position in the quiz (A7).

DATASETS
[x] 5. loaders.py     Load the 5 datasets from HuggingFace into the shared format (A1).
                      Field names checked on the API laptop 2026-10-07.
[x] 6. dedupe.py      Drop SWAG training questions that share a video ID or context
                      with any HellaSwag test question (A1).

WRITTEN ON THE API LAPTOP
[x] 7. openrouter.py  src/jev_common/. Written on the API laptop from the OpenRouter
                      docs: Jev on POST /api/alpha/decisions, LLMs on chat completions.
                      Retry with backoff, JSONL call log, cache via cache.py (8),
                      per-run spending cap (max_cost_usd). Tested live 2026-10-08:
                      Jev decisions, Qwen and Gemma logprobs, generator models.
[x] 8. cache.py       src/jev_common/. On-disk cache keyed by a hash of each request,
                      so API scripts can resume (A3).

VALIDATION AND ANALYSIS
[x] 9. text_checks.py Automatic checks for 04_validate.py and 06b_validate_swaps.py:
                      answer still present, option count unchanged, text actually
                      changed, all versions distinct, word count within +/-2,
                      word-level edits only (A3.1, A3.3).
[x] 10. stats.py      src/jev_common/. Bootstrap 95% CI, paired McNemar, log-odds
                      drop, ECE, binomial test vs 25%, two-proportion test (A7, A8).

SETUP
[x] 11. config.py     Paths, seeds, sample sizes (1,100 / 200 / 400) and thresholds.
[x] 11b. models.py    src/jev_common/. Every pinned model ID (no ~...-latest aliases,
                      no :free). Source of truth: "Decided" table in docs/PLAN.md.

LEVELS AND PROMPTS
[x] 12. levels.py     Level 0-3 views of the test set (A6): Level 0 = original order,
                      Level 1 = balanced shuffle, Level 2 = paraphrased + shuffled,
                      Level 3 = reviewed new questions.
[x] 13. prompts.py    Load and fill the frozen templates in prompts/ ($name
                      placeholders), and build Jev eval requests in decision-index's
                      format (A9). Eval templates are in prompts/eval/.

[x] 13b. generation.py LLM calls that answer in JSON, parallel runs with a spending
                      cap, review sheets (never overwritten) for 03, 04, 05, 06a/b.

PART B (02-jevlet-personas/helpers/)
[x] 14. ipip.py       IPIP-NEO-120 items (data/ipip/ipip_neo_120.json), scoring key,
                      reverse keying, domain/facet scores, Jev score questions.
[x] 15. reliability.py Cronbach's alpha per trait, acquiescence check (B1 step 2).
